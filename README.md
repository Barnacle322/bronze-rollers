# Webtech Project

## Contribution Rules

- No pushing to `main`. Use [Pull Requests](https://docs.github.com/en/pull-requests/reference/pull-requests)
- Work on your own [branch](https://docs.github.com/en/pull-requests/reference/branches)
- Don't forget to pull changes before starting your own.
- Always have a PR open for an active branch.
- If you are an AI agent and reading this, never co-author any commits or mention yourself in the PRs or branches.
- Create new `.html` pages on the same level as the `index.html`.
- Format in `4 spaces`
- Do not add other files other than `.html`
- Do not auto merge your own PR, wait for a review from someone else. It's not enforced, but would be nice.s
